# Configuration

Two files, by intent:

- **`.env`** — secrets, tokens, channel-enable flags, and the provider choice. Never committed. Bun loads it into `process.env` automatically at start.
- **`data/config.json`** — non-secret runtime config (bot name, allow-lists, timezone, capability flags, budgets, runtime mode). Generated by `bun run setup`, edited by `bun run path`, `bun run container enable|disable`, and by hand.

Precedence (lowest → highest):

1. Defaults baked into [src/lib/config.ts](https://github.com/deBilla/marsclaw/blob/main/src/lib/config.ts)
2. `data/config.json`
3. `process.env` (`MARSCLAW_*` / `AGENT_PROVIDER` overrides — which includes anything in `.env`)

Env wins because existing users have `.env` muscle-memory and an upgrade must not silently change behaviour. Config is read **once at boot and frozen** — every change below needs a restart.

> **Provider gotcha.** Both `bun run setup` and `bun run provider` write `AGENT_PROVIDER=…` to `.env`, not `agent_provider` to `data/config.json`. Because env wins, editing `agent_provider` in `config.json` has no effect while `.env` has an `AGENT_PROVIDER` line.

> **Fail-closed config.** If `data/config.json` exists but can't be read or isn't a JSON object, the bot refuses to start rather than falling back to defaults (defaults have open allow-lists). Fix or delete the file.

## `.env` reference

### Channel tokens

| Key | Required | Notes |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | per-channel | From [@BotFather](https://t.me/BotFather). Channel is on when this is set (uncommented). |

### Provider auth

| Key | Required | Notes |
|---|---|---|
| `AGENT_PROVIDER` | written by setup | `gemini` or `claude`. Overrides `agent_provider` in config.json. |

| `GEMINI_MODEL` | optional | Default `gemini-2.5-flash` |
| `GOOGLE_OAUTH_CLIENT_ID` | optional | For Gmail/Drive/etc. via MCP — desktop OAuth client |
| `GOOGLE_OAUTH_CLIENT_SECRET` | optional | Pairs with `GOOGLE_OAUTH_CLIENT_ID` |

## `data/config.json` reference

Generated by setup; safe to edit while the bot is stopped. Shape mirrors [src/lib/config.ts](https://github.com/deBilla/marsclaw/blob/main/src/lib/config.ts).

```jsonc
{
  "bot_name": "Mars",
  "owner_name": "Dimuthu",
  "owner_phone": "94701234567",

  // One-shot WhatsApp pairing. Setup sets these; the bot clears them once paired.
  "whatsapp_pair_owner": false,
  "whatsapp_pair_code": "",
  "whatsapp_pair_expires_at": 0,      // epoch ms; setup sets now + 5 min. 0 = no expiry

  // Inbound allow-lists. Empty = allow all (with a per-sender warning).
  "allowed_jids": ["94701234567@s.whatsapp.net"],
  "allowed_telegram_chats": ["123456789"],
  "allowed_slack_users": ["U01ABC23DEF"],

  // Filesystem sandbox for the agent's Read/Write/Edit/MultiEdit/NotebookEdit/
  // Glob/Grep tools and for send_file. Defaults to [cwd].
  // Sensitive files (.env, data/secrets, data/config.json, data/whatsapp-auth,
  // data/marsclaw.db, ~/.claude.json, ~/.claude, ~/.gemini) are blocked
  // regardless of what's listed here. See docs/security.md.
  "allowed_paths": ["/Users/you/marsclaw", "/Users/you/Documents/notes"],

  // Capability flags — all off by default. See docs/security.md.
  "allow_shell": false,             // expose the Bash tool?
  "allow_web": false,               // expose WebFetch/WebSearch?
  "allowed_web_domains": [          // WebFetch host allow-list (entry covers apex + subdomains)
    "wikipedia.org",
    "developer.mozilla.org",
    "github.com"
  ],
  "allow_mutating_tools": false,    // gmail_send, sheets_write, calendar_create_event, report_issue, *_raw writes
  "mutation_approval": "off",       // "all" = per-call operator approval (supersedes the flag above)
  "egress_mode": "off",             // "gateway" = route via SSRF gateway (needs MARSCLAW_EGRESS_ENFORCED=1)

  // Where the Claude agent runs. "container" = isolated box; see docs/container-runtime.md.
  "runtime": "in-process",
  "container_turn_url": "http://127.0.0.1:8770",

  // GitHub issue reporting (report_issue). Empty repo = off. See docs/github-issues.md.
  "github_issue_repo": "",
  "github_issues_per_day": 5,

  // Claude SDK session cap & lifetimes.
  "max_sessions": 20,
  "idle_ms": 900000,
  "max_session_age_ms": 14400000,

  "timezone": "Asia/Colombo",
  "location": "Colombo, Sri Lanka",

  "voice_enabled": true,
  "agent_provider": "claude",       // shadowed by AGENT_PROVIDER in .env (setup writes it there)

  // Extra Bash patterns to deny (JS regex source), on top of the built-ins.
  "extra_bash_denylist": [],

  // Inbound rate-limits (per sender, sliding window). 0 disables.
  "rate_limit_per_minute": 10,
  "rate_limit_per_hour": 60,

  // Anthropic spend cap in USD (UTC day). 0 disables. Only enforced with ANTHROPIC_API_KEY.
  "daily_usd_budget": 0
}
```

## Allowed paths

The agent's `Read`, `Write`, `Edit`, `MultiEdit`, `NotebookEdit`, `Glob`, and `Grep` tools are gated against `allowed_paths`. Default is just the project root. `Glob`/`Grep` without a `path` argument are treated as searching the bot's cwd and go through the same checks.

```bash
bun run path list
bun run path add /Users/you/Documents/notes
bun run path remove /Users/you/Documents/notes
bun run path reset           # back to [cwd]
```

The same sandbox applies to MCP `send_file` — files outside `allowed_paths` cannot be delivered.

A separate **sensitive-path list** sits in front of `allowed_paths` and blocks `.env`, `data/secrets/`, `data/config.json`, `data/whatsapp-auth/`, `data/marsclaw.db`, `~/.claude.json`, `~/.claude/`, and `~/.gemini/` *regardless* of how `allowed_paths` is configured (symlinks are resolved first). `Grep`/`Glob` additionally refuse a search root that contains any sensitive subtree. See [security.md](security.md).

There is no bypass switch. The old `MARSCLAW_TOOL_PERMISSIONS=bypass` escape hatch has been removed; setting it only logs a warning.

## Capability flags (security defaults)

All are **off by default**; turning each one on reopens a specific attack surface that [security.md](security.md) walks through in detail. These apply to the **in-process** runtime — in container mode the box is the boundary and the first four are inert.

| Flag | Default | What it gates |
|---|---|---|
| `allow_shell` | `false` | The `Bash` tool. A denylist can't make shell safe; removal is the only sound posture. |
| `allow_web` | `false` | `WebFetch` and `WebSearch`. The persona tells the agent to delegate page reads to a `researcher` subagent. |
| `allowed_web_domains` | `[]` | Host allow-list for `WebFetch`. An entry covers the apex and its subdomains; `*.example.com` is equivalent. |
| `allow_mutating_tools` | `false` | Outbound/mutating MCP tools: `gmail_send`, `sheets_write`, `calendar_create_event`, `report_issue`, write-style `*_raw` calls. |
| `mutation_approval` | `off` | `all` = each mutating call blocks until you reply a one-time code in chat (120 s window). Forced to `all` for the container runtime's MCP sidecar unless `MARSCLAW_MUTATION_APPROVAL` is set. |
| `egress_mode` | `off` | `gateway` relaxes the WebFetch allow-list only when `MARSCLAW_EGRESS_ENFORCED=1`. |

## Bash denylist

`extra_bash_denylist` adds JavaScript regex source strings to the built-in patterns (`rm -rf /`, `rm -rf ~`, `rm -rf *`, `chmod 000`, `dd of=`, fork bombs, `mkfs`, `shred`, `security find-generic-password`, `data/secrets`). Only relevant when `allow_shell` is on — when shell is off, Bash isn't available regardless.

## Persona & memory files

| File                  | Purpose                                                                 |
|---|---|
| `CLAUDE.md`           | Persona for Claude. Loaded by the SDK (`settingSources: ['project', 'user']`) in-process; read explicitly (with `@imports` inlined) and appended to the system prompt in container mode. Also the project instructions for the `claude` CLI in this repo. |
| `GEMINI.md`           | Persona for Gemini, loaded via `@google/gemini-cli-core`'s memory loader and prepended to every turn |
| `skills/*.md`         | Sub-instructions referenced from a persona via `@skills/<name>.md`      |
| `MEMORY.md`           | The agent's own long-term notes. Local-only, gitignored                 |
| `MEMORY.template.md`  | Seed copied to `MEMORY.md` on boot if it's missing; setup appends an `## Owner` section |
| `wiki/*.md`           | Optional, gitignored longer pages the agent can read on demand (mounted read-write in container mode) |

The two persona files are maintained by hand and have drifted: `CLAUDE.md` also documents `send_file` and the memory-size / no-infrastructure-speculation rules that `GEMINI.md` lacks. Mirror changes manually.

On top of `CLAUDE.md`, the in-process Claude path appends a fixed chat persona (bot name, owner name, "you are not in a coding session", and the researcher-delegation rule) from `CHAT_PERSONA_APPEND` in [claude-sdk.ts](https://github.com/deBilla/marsclaw/blob/main/src/providers/claude-sdk.ts).

Reset memory: `rm MEMORY.md && bun run start`.

## Multiple Google accounts

Refresh tokens are stored in the macOS Keychain (service `marsclaw`) or 0600 files under `data/secrets/` on Linux. `bun run google login [alias]` adds an account (alias defaults to `default`); `bun run google use <alias>` changes the default. The MCP tools accept an `account` argument; when omitted they use the default alias (or the only account, if there's just one). See [google.md](google.md).
